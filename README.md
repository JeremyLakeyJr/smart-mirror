# Smart Mirror Tony

A smart mirror project integrating Tony AI with voice and camera features.

## Features
- Voice interaction via TTS
- Camera feed for facial recognition
- Display Tony's responses on mirror
- Calendar, weather, news overlays

## Setup
- Raspberry Pi with mirror display
- Camera module
- OpenClaw for AI integration

## Hardware
- Two-way mirror
- LCD screen behind
- Microphone/speaker
- Pi Camera

## Software
- Node.js for mirror UI
- OpenClaw API for Tony
- Canvas for display rendering
